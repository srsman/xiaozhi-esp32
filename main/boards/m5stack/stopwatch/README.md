# M5Stack StopWatch (小智 AI 秒表智能手表)

[English](README.md) | [中文](README.md)

M5Stack StopWatch 是一款基于 ESP32-S3 双核处理器打造的高颜值圆形触摸屏智能秒表 / 智能手表设备。本项目在完整保留小智 AI 实时语音大模型对话交互（离线唤醒、Muse 动态数字人表情、流式双工语音、MCP 多端控制）的基础上，全量移植并深度融合了 M5Stack 原生应用生态与趣味互动角色，共 11 款精选应用，专为 466×466 圆形 AMOLED 屏深度定制。

---

## 🌟 核心特性与应用生态

### 1. 深度融合的 11 大核心功能应用
- **小智 AI 语音助手 (XiaoZhi AI)**：
  - 支持离线低功耗语音唤醒（“你好小智”），声纹识别鉴定说话人身份；
  - 动态 Muse 数字人表情头像，支持开心、疑惑、思考等丰富情绪呈现；
  - 全双工低延迟实时大模型对话与流式 TTS 语音播报；
  - 集成设备端 MCP（Model Context Protocol）协议，支持控制音量、背光与硬件交互。
- **表盘生态 (Watch Face)**：
  - 内置经典指针（极速平滑走针）、极客数字（高对比度赛博风）、极简现代等多种表盘风格；
  - 接入 RX8130 独立高精度 RTC 实时硬件时钟，支持断电走时与开机自动校时。
- **专业秒表 (Stopwatch)**：
  - 官方级毫秒精度计时内核，支持多段圈数计次（Lap Time）与统计分析。
- **个性化智能胸牌 (Badge)**：
  - **3 款内置极客卡片**：提供赛博 AI 工牌、星际领航员通行证、数字矩阵极客徽章 3 套精美预置矢量主题；
  - **全屏多维触控手势**：支持全屏向左 / 向右滑动切换（Swipe Left / Right）、屏幕左右边缘轻触切屏、底部动态小圆点指示当前卡片位置；
  - **手机免 App 无线传图**：长按屏幕触发确认对话框，点击“Edit”一键开启专属低功耗 Wi-Fi AP 热点；手机连接热点后打开浏览器 (`http://192.168.4.1`)，即可直观多槽位上传、裁剪缩放预览、激活与删除照片；
  - **原生硬件 JPEG 解码与防黑屏容灾**：采用 ESP32-S3 硬件加速与 PSRAM 高速解码，即便图片异常也自动平滑降级至内置极客胸牌，保证绝不黑屏；
  - **优雅平滑退出**：点击手机端网页“Done”或按下手表实体侧键即可秒级干净退出热点，并自动将轮播定位至最新激活的照片槽位，后台无缝恢复小智网络。
- **定时闹钟 (Alarm Clock)**：
  - 支持多时间段设定、周期循环响铃与内置扁平马达触觉震动提醒。
- **趣味幸运转盘 (Lucky Wheel)**：
  - 支持全屏物理惯性滑动旋转与随机结果判定。
- **动态音频频谱 (Audio FFT)**：
  - 硬件 ES8311 音频 Codec 实时采样，高帧率动态跳动柱状频谱可视化。
- **水平仪 (IMU)**：
  - 基于板载 BMI270 六轴运动传感器，提供高灵敏度电子水平仪与倾角动态读数。
- **重力流体小球 (FluidBox)**：
  - 真实物理碰撞与重力感应，倾斜手表即可观察微观粒子碰撞动态。
- **系统设置 (Settings)**：
  - 支持 AMOLED 屏幕无极亮度调节、扬声器音量控制、Wi-Fi 状态查询与系统固件信息。
- **咕噜咕噜互动角色 (Guruguru)**：
  - **9 方向眼神/头部跟踪**：支持 360° 触控实时视线注视（Top-Left 至 Bottom-Right 9 方向），瞳孔具备全真平滑模拟阻尼感；
  - **内置萌系二次元角色**：开箱即用，自带猫耳、红晕腮红与萌系猫嘴，支持随机眨眼与轻触心动反馈；
  - **六轴重力感应联动**：支持陀螺仪姿态交互，手表倾斜时角色视线随重力偏转，双击底部可随时启闭 IMU 模式；
  - **自定义切片图拓展**：长按屏幕唤起确认框，支持开启独立 AP 上传专属二次元角色 9 宫格切片。
- **3D 秒表圆球物理抽屉 (App Launcher)**：
  - 采用独创的 3D 仿真实体秒表物理滚轮圆球设计，菜单文字标签与球体精确动态对齐，滑动流畅无遮挡。

## 🛠️ 硬件技术规格

| 项目 | 规格参数 | 说明 |
| :--- | :--- | :--- |
| **主控芯片** | ESP32-S3 (Xtensa 双核 240MHz) | 支持硬件矢量指令集加速 |
| **存储配置** | 16MiB Flash + 8MiB Octal PSRAM | 高速八线内存，提供充沛的图像解码缓冲 |
| **显示屏幕** | 1.75 英寸 AMOLED 圆形触摸屏 | 分辨率 466 × 466, QSPI 接口, CO5300 驱动控制器 |
| **触控芯片** | CST820B 高灵敏度电容触摸屏 | I2C 接口 @ 0x15, 支持滑动、长按、多点手势 |
| **音频编解码** | ES8311 高保真低功耗 Audio Codec | I2S 双工传输，外接高性能硬件功放 |
| **电源与电池** | M5PM1 智能电源管理单元 | I2C @ 0x6E，支持库仑计电量百分比、充电监测 |
| **IO 扩展芯片** | M5IOE1 IO 扩展器 | I2C @ 0x4F，统一管理屏幕供电、复位、震动马达等外设 |
| **传感器与RTC** | BMI270 (六轴 IMU) + RX8130 (独立 RTC) | 支持重力感应、姿态计算与硬件时钟走时 |
| **触觉反馈** | 内置微型线性扁平震动马达 | 支持触控震动反馈与闹钟事件振动 |

## 🗂️ 16MB Flash 分区架构设计

本项目采用专用的优化存储架构 `partitions/v2/16m_stopwatch.csv`，在兼顾小智 AI 双分区 OTA 升级的前提下，开辟了专用的独立用户数据存储区：

| 分区标识 | 分区类型 | 子类型 | 偏移地址 | 容量大小 | 核心用途说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `nvs` | data | nvs | 0x9000 | 16 KB | Wi-Fi 凭证、系统配网与用户设置存储 |
| `otadata` | data | ota | 0xd000 | 8 KB | OTA 无缝双备份升级状态标识 |
| `ota_0` | app | ota_0 | 0x20000 | **5.125 MB** | 主运行固件（包含小智 AI 全套核心 + 10 款原生应用） |
| `ota_1` | app | ota_1 | 0x540000 | **5.125 MB** | 完整对等的 OTA 备用升级固件分区 |
| `storage` | data | fat | 0xa60000 | **1.625 MB** | FATFS 文件系统（专门持久化存储用户上传的胸牌图片） |
| `assets` | data | spiffs | 0xc00000 | **4.000 MB** | 包含 Muse 表情图集、UI 矢量图标、字体资产与系统音效 |

## 🚀 编译与固件构建

### 前置环境准备
确保已安装并激活 ESP-IDF 编译工具链（推荐 ESP-IDF v6.0.1 或 v6.1）：
```bash
# Windows PowerShell
. D:\path\to\esp-idf\export.ps1

# Linux / macOS
source /path/to/esp-idf/export.sh
```

### 1. 标准固件编译
```bash
python scripts/build.py m5stack/stopwatch --name m5stack-stopwatch
```

### 2. 打包生成完整发布包 (Release ZIP)
若需生成用于分发的压缩包（包含合并固件与一键烧录脚本），添加 `--zip` 参数：
```bash
python scripts/build.py m5stack/stopwatch --name m5stack-stopwatch --zip
```
执行完毕后，将在 `releases/` 目录下生成 `v2.5.3_m5stack-stopwatch.zip`。

## ⚡ 极速烧录指南

将 M5Stack StopWatch 通过 Type-C 数据线连接至电脑（假设端口为 `COM8`）：

### 方式 A：使用 idf.py 一键烧录并监控（推荐）
```bash
idf.py -p COM8 flash monitor
```

### 方式 B：使用合并固件极速烧录
编译后生成的 `build/merged-binary.bin` 已经集成了 Bootloader、分区表、OTA 初始化数据、主固件以及 Assets 资源包，可直接从 `0x0` 地址刷写：
```bash
python -m esptool --chip esp32s3 -p COM8 -b 921600 write_flash 0x0 build/merged-binary.bin
```

## 📖 胸牌无线传图 (Badge) 交互全流程

1. **进入应用**：在物理滚轮应用抽屉中点击“胸牌 (Badge)”图标进入；
2. **手势切换**：在屏幕上**向左或向右滑动**，或**轻触屏幕左右两侧边缘**，即可在内置赛博极客卡片与已上传的照片间流畅轮播，底部圆点指示当前卡片索引；
3. **唤起编辑**：在任意胸牌卡片上**长按屏幕**，屏幕弹出确认弹窗 `Enter badge edit?`；
4. **启动热点**：点击绿色的 `[Edit]` 按钮，手表屏幕提示 `Starting WiFi AP...`，随后显示热点名称（如 `M5StopWatch-XXXX`）与访问地址 `http://192.168.4.1`；
5. **手机传图**：
   - 打开手机 Wi-Fi 列表，连接该热点（免密码）；
   - 在手机浏览器中输入 `http://192.168.4.1` 打开胸牌管理器网页；
   - 网页支持 6 个独立槽位管理：点击槽位上传 JPG/PNG 图像，支持手势拖动与平移缩放裁剪；
   - 点击“Upload”上传图片，点击“Set Active”激活对应卡片；
6. **优雅退出**：
   - 上传或整理完毕后，直接点击网页底部的 **[Done]** 按钮，或按下手表侧边实体按钮；
   - 手表屏幕短暂提示 `Exited edit mode` 后，将**全自动退出 AP 并切回胸牌浏览界面**，第一顺位显示最新激活的照片。
